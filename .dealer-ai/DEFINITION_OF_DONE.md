# DEFINITION OF DONE

Un requisito puede marcarse PASS solamente si cumple:

1. Codigo implementado.
2. Build exitoso.
3. Tests relacionados exitosos.
4. Sin regresion evidente.
5. Permisos validados.
6. Manejo de errores.
7. Mobile revisado cuando corresponda.
8. Documentado.
9. No toca produccion.
10. No utiliza datos reales.

Si falta integracion externa:
PENDING_EXTERNAL

Si existe bloqueo tecnico:
BLOCKED

Si falla:
FAIL

Nunca usar PASS por suposicion.
